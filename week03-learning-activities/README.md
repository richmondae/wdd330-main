# Week 3 Learning Activities (not part of the SleepOutside app)

These two files are standalone deliverables for the individual W03 learning
activities. They are NOT part of the SleepOutside project and should not be
committed into this repo's src/ folder or built by Vite.

- w03-fetch-users.html
  For "W03 Learning Activity: Third-Party APIs" / "Review: The Fetch API".
  Open it directly in a browser, or paste the <script> contents into a
  CodePen JS panel and the body's <ul> into the HTML panel.

- w03-form-validation.html
  For "W03 Learning Activity: HTML Forms and User Input Validation".
  Fork the course's provided CodePen into your own account first, then
  copy this file's HTML/CSS/JS into the matching panels of your fork.
  I don't have access to the original CodePen's exact starter markup,
  so double check your fork's field names/ids match before pasting.
